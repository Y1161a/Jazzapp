## 🌟 نبذة عن التطبيق (Vision)

**Jazzapp** هو تطبيق ويب تقدمي (Progressive Web App - PWA) مخصص للهاتف المحمول، صُمم خصيصاً لأصحاب ومديري المقاهي لمتابعة كافة الالتزامات المالية الدورية، فواتير الكهرباء والماء والإنترنت والأداءات البلدية والضرائب، بالإضافة إلى إدارة وتتبع مخزون المواد الأساسية (بن، حليب، أكواب، سكر...) في واجهة موحدة أنيقة مستوحاة من أجواء مقاهي الجاز الكلاسيكية.

التطبيق يعمل **بشكل محلي كامل 100% (On-Device Local Storage)** دون الحاجة إلى خادم سحابي أو قواعد بيانات خارجية، ويدعم العمل دون اتصال بالإنترنت (Offline-First) مع إمكانية التثبيت المباشر على شاشة الهاتف، وتصدير/استيراد نسخة احتياطية من البيانات بضغطة زر واحدة.

## 🚀 الأقسام الأربعة الرئيسية للتطبيق المبسّط (The 4 Core Modules)

عند فتح التطبيق تظهر مباشرة 4 بطاقات وأيقونات واضحة للاختيار السريع:

### 1. 📋 الالتزامات المادية (الفواتير، الصيانة، الإنترنت...)
- متابعة فواتير الكهرباء، الماء، الإنترنت، كراء المحل، الصيانة والتجهيزات، والأداءات والضرائب.
- تحديد موعد تذكير يدوي وتنبيهات صوتية وإشعارات الهاتف (PWA Notifications).
- التبديل بنقرة واحدة بين مستحق ومدفوع.

### 2. 📦 المخزون من السلع (المواد الاستهلاكية)
- بن، حليب، أكواب، سكر، سيروب ومواد التنظيف.
- مؤشر تحذير فوري عند نزول أي مادة دون الحد الأدنى.
- أزرار سريعة للحركات اليومية (+ / -) وسجل التوريد.

### 3. ⚖️ نقطة التعادل (كم من مشروب يباع لتغطية المصاريف)
- حساب دقيق للمصاريف الشهرية (تلقائياً من الالتزامات أو إدخال يدوي).
- احتساب هامش الربح لكل فنجان قهوة ومشروب.
- احتساب عدد المشروبات المطلوب بيعها يومياً وشهرياً لتغطية كافة المصاريف.
- مؤشر تقدّم يومي مباشر يوضح متى تبدأ الأرباح الصافية الحقيقية للمقهى!

### 4. 💰 العائد المالي لليوم والمصاريف (الصندوق اليومي)
- تسجيل مبيعات ومداخيل اليوم (العائد المالي).
- تسجيل مصاريف اليوم النثرية (المشتريات السريعة).
- حساب فوري لصافي أرباح اليوم وصافي الشهر وسجل الأيام السابقة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 18 + TypeScript + Vite 6
- **Styling**: Tailwind CSS مع لوحة ألوان دافئة مخصصة وخطوط Google (Cairo & Inter)
- **Icons**: Lucide React
- **Audio**: Web Audio API (توليف نغمات جاز واقعية دون ملفات وسائط خارجية)
- **PWA**: Web App Manifest + Service Worker للتخزين المؤقت والإشعارات المتقدمة
- **Storage**: Browser LocalStorage & IndexedDB

## 💻 طريقة التشغيل محلياً (Getting Started)

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل السيرفر المحلي
npm run dev

# 3. بناء النسخة الإنتاجية
npm run build

# 4. معاينة البناء
npm run preview
```

## 📱 كيفية فتح التطبيق واستخدامه على الهاتف المحمول

### الطريقة الأولى: الرابط المباشر عبر الإنترنت (GitHub Pages) 🌐
بعد رفع التعديلات، يتم نشر التطبيق تلقائياً عبر GitHub Actions:
- **رابط التطبيق المباشر**: `https://y1161a.github.io/Jazzapp/`
- **خطوة لمرة واحدة في GitHub**:
  1. ادخل إلى إعدادات المستودع: `Settings` -> `Pages`.
  2. في قسم `Build and deployment` -> اختر `Source`: **GitHub Actions**.
  3. سيتم النشر وتعمل جميع ميزات PWA والإشعارات والتخزين دون اتصال عبر بروتوكول HTTPS الآمن!

### الطريقة الثانية: الفتح الفوري عبر شبكة الواي فاي المحلية (Wi-Fi) 📶
إذا كان هاتفك وحاسوبك متصلين بنفس شبكة الواي فاي:
1. قم بتشغيل السيرفر على الحاسوب:
   ```bash
   npm run dev
   ```
2. افتح متصفح هاتفك (Chrome أو Safari) واكتب الرابط التالي:
   ```
   http://192.168.1.9:3000
   ```

## 📲 التثبيت على الهاتف كـ تطبيق مستقل (PWA)

1. افتح رابط التطبيق على متصفح الهاتف (Safari على iPhone أو Chrome على Android).
2. اضغط على زر الخيارات (⋮) أو زر المشاركة (Share).
3. اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen / Ajouter à l'écran d'accueil)**.
4. سيظهر تطبيق **Jazzapp** كأيقونة تطبيق رسمي مستقل على شاشة هاتفك، يعمل بكامل الشاشة (Full-screen) وبدون شريط متصفح وبإمكانية الاستخدام دون إنترنت (Offline).
